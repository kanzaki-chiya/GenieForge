# 补丁目录

本目录存放语义补丁（YAML）。应用内「补丁」页读写的就是这里的 `*.yaml` 文件。

- 每个补丁是独立的纯文本文件，可以用 Git 管理、分享和复用；
- 补丁按名称 / 正则 / 签名定位目标，不依赖 ID，官方更新后可在新版 dat 上重新预览并应用；
- `manifest.yaml` 用于记录基准版本、补丁顺序与官方 dat 哈希，目前仅作人工记录，应用内不会自动读取。
- “记住选择”会把冲突步骤改写为按名称精确匹配（每个选中条目各一步）。

格式说明见 [`docs/api.md`](../docs/api.md#补丁格式)，示例见 `001_example.yaml`。
