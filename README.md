> 一款面向《帝国时代 II：决定版》Mod 制作者的桌面工具，让你**告别每次官方更新都要全量重做**的痛苦。

## 这是什么？

帝国时代2决定版的游戏数据全部存放在一个约 10MB 的 `empires2_x2_p1.dat` 文件里（单位、科技、效果、文明加成、费用等）。传统的 AGE 工具只能「打开 → 改 → 存」，于是每次官方更新后，由于 ID 漂移、新内容插入，你的修改**全部作废，只能在新版上从头再改一遍**。

本工具在完整解析 dat 的基础上，提供了三大能力，彻底改变这种工作方式：

- **增量修改**：把改动存成「语义化补丁」，官方更新后一键套用，只需处理少数冲突。
- **批量对比**：两个 dat 的差异一目了然，不再人肉对照。
- **关联跳转**：科技 ↔ 效果 ↔ 单位 双向跳转，不再靠编号猜。

## 核心特性

### ✨ 增量修改 —— 一次修改，长期复用
把你的改动写成**补丁**（比如「织布机金费改为 30」「所有 `C-Bonus*` 科技加成翻倍」）。官方更新后，直接在新版 dat 上套用补丁，工具自动匹配目标（名称 → 签名 → 相对位置三级匹配），只有极少数需要人工确认。

### 🔍 批量对比差异
同时打开两个 dat，自动列出三层差异：
- **表级**：科技/文明/效果各多了多少、少了多少；
- **记录级**：同名条目哪个字段改了（红绿高亮并排对比）；
- **引用级**：哪些同名科技的 ID 漂移了（这正是官方更新坑人的地方）。

### 🔗 关联跳转
点任意科技，直接看到它引用的效果、前置科技、所属文明；反向也能查「谁引用了这个效果」。所有编号自动翻译成中文名，悬停即预览。

### 🧰 批量修改
多选批量改、按条件筛选改、查找替换、常用规则存成模板（如「双倍文明特效」），改前预览影响范围，改后一键撤销。

### 📦 生成 / 应用 mod 补丁
- 从「官方版 vs 我的 mod 版」的差异**反向生成补丁**；
- 或把本次编辑操作直接导出为补丁；
- 补丁是纯文本文件，可版本化、可分享、可复用。

### 🕘 版本管理
记录每次改动历史，随时回滚到任意版本；工程 = 基准官方版本 + 补丁集合，官方更新时自动提示「可 rebase」。

### 🔄 GitHub 自动更新
工具自身连接 GitHub，启动时检查新版本并一键更新；补丁工程也可同步到 GitHub 备份/协作。

### 🤖 公共 API（进阶）
提供完整的 HTTP 接口，可以让你自己的脚本或 AI Agent 自动完成「读数据 → 批量修改 → 应用补丁 → 写回」，无需手动点界面。

## 快速开始

### 安装

1. 从 [GitHub Releases](../../releases) 下载最新版安装包；
2. 解压运行（首次启动会自动引导完成初始配置）；
3. 应用会随官方发布自动更新（可在设置中切换手动/自动）。

### 首次配置

1. 启动后，在「设置」中**选择游戏目录**（工具会自动探测 Steam / 微软商店的安装位置）；
2. 确认工具找到了 `empires2_x2_p1.dat` 和语言文件（用于把单位/科技名显示成中文）；
3. 完成，开始使用。

### 打开并编辑

1. 点击「打开 dat」，选择要编辑的 `empires2_x2_p1.dat`；
2. 左侧导航切换科技 / 效果 / 文明 / 单位等表；
3. 双击单元格直接改数值，引用字段（如效果 ID）用下拉选择器；
4. `Ctrl+S` 保存。

## 使用指南

### 官方更新后的推荐工作流（核心场景）

```
① 打开官方新版 dat
② 点击「应用补丁」，选择你维护的补丁集合
③ 工具自动匹配 + 列出冲突（通常只有几条）
④ 人工处理冲突，其余一键套用
⑤ 保存为新版 mod，提交版本记录
```

> 从此官方每次更新，你只需要处理**少量适配**，而不是全量重做。

### 批量修改示例

- **批量改费用**：筛选「所有炮类单位」→ 全选 → 右键「批量操作」→ 费用 ×1.2。
- **套用模板**：选「双倍文明特效」模板 → 预览影响科技数 → 确认执行。
- **查找替换**：`Ctrl+F` 按字段查找并批量替换。

### 对比两个版本

1. 「工具」→「对比 dat」，选择基准与目标两个文件；
2. 查看顶部摘要卡片（新增/删除/修改数量）；
3. 点击任一变更，左右并排看红绿高亮差异；
4. 需要时直接把差异「导出为补丁」。

### 关联跳转

- 点击任何 ID / 名称 → 跳转到对应条目；
- `Ctrl+Click` 在新面板打开；
- 右键 →「谁引用了这个」查看反向引用。

## 公共 API（供脚本 / Agent 调用）

启动工具后，API 默认运行在 `http://127.0.0.1:8342`，完整文档见 `/docs`。

示例：让 Agent 自动完成一次修改

```bash
# 加载 dat
curl -X POST http://127.0.0.1:8342/api/dat/load \
     -H "Content-Type: application/json" \
     -d '{"path":"D:/AoE2DE/resources/_common/dat/empires2_x2_p1.dat"}'

# 应用一条语义补丁（织布机金费改 30）
curl -X POST http://127.0.0.1:8342/api/patch/apply \
     -H "Content-Type: application/json" \
     -d '{"patch":"steps:\n  - target: {table: techs, name: Loom}\n    op: set\n    field: resource_costs.2.amount\n    value: 30"}'

# 保存
curl -X POST http://127.0.0.1:8342/api/dat/save \
     -H "Content-Type: application/json" \
     -d '{"path":"D:/AoE2DE/resources/_common/dat/empires2_x2_p1_mod.dat"}'
```

## 常见问题（FAQ）

**Q：会不会改坏游戏文件？**
A：工具读写的是你指定的 dat 副本，建议先备份。写回采用字节级无损格式，与原版完全兼容。

**Q：官方更新后补丁失效怎么办？**
A：不会失效。补丁按「名称/签名」定位而非固定 ID，官方更新导致的 ID 漂移会被自动化解；少数无法自动匹配的会列出让你确认。

**Q：中文名显示不出来？**
A：在「设置」中确认语言文件路径正确（游戏目录下 `key-value-strings-utf8.txt`）。

**Q：工具支持哪些 dat 版本？**
A：决定版 `VER 7.8 / 8.4 / 8.8` 等，随官方新版本持续跟进。

## 技术说明（给想看原理的人）

- 数据核心基于开源库 [genieutils-py](https://github.com/SiegeEngineers/genieutils-py)；
- dat 格式 = zlib 压缩 + Genie 引擎结构化数据（公开格式）；
- 后端 FastAPI + 前端 Vue 3，桌面壳为原生窗口，API 与桌面 UI 共用同一套能力。

> 更完整的产品与技术方案见 [`方案C_桌面应用产品技术方案.md`](方案C_桌面应用产品技术方案.md)；可行性分析见 [`工具优化设计方案.md`](工具优化设计方案.md)。
